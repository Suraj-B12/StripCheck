Help us survey the literature for StripCheck

StripCheck is a college Agentic AI project that checks whether a photographed medicine pack's batch is on India's CDSCO drug-quality alert lists. Your model researches one theme at a time and returns a report in a fixed format, which we check, verify and fold into our paper and thesis.

How to run it

  1. Use a model with live web search or a deep-research mode. Without browsing it can still help, but it must say browsing: no.
  2. Open a new conversation for each theme. Press Copy master + card on a theme below and paste it as your first message.
  3. If the answer stops early, send Continue exactly where you stopped, in the same format. and keep every part.
  4. Save the whole answer, unedited, as a Markdown file with the name shown on the card.
  5. Send the files back to the StripCheck team. Start with the Priority 1 themes; even three or four help.

What happens to your files

    
A checker validates each file against the format (header, eleven sections, source fields, citation keys, matching BibTeX, a DOI or URL for every source) and flags sources we already have. Every new source is then verified against Crossref, arXiv, Semantic Scholar or the publisher before it can enter the paper's bibliography. The thesis credits the external model in its survey method.
