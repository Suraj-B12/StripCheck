India's Central Drugs Standard Control Organisation publishes monthly lists of drug batches that
failed quality tests or were declared spurious, yet a person holding a strip of tablets cannot easily compare its batch number with these lists. The check is harder than a lookup: optical character recognition misreads single characters with full confidence, the
same batch number appears on unrelated products, and some listed batches have a sibling from the
same manufacturer that differs in one look-alike character. We built StripCheck, an offline agent whose bounded plan-act-observe loop calls tools for
exact and confusion-aware batch search, grades each candidate field by field as in record linkage,
asks the person to confirm doubtful characters before any alarm, and passes each draft verdict to a
rule-based verifier that turns unsupported drafts into an abstention. A local language model can choose the action at two
branch points or pick every tool in a ReAct loop whose allowed tools the rules fix; a rejected draft is revised once, and a
vision model may read an unreadable batch only for the person to confirm. We
compared the agent with a lookup baseline on \res{ResN} synthetic packs rendered from real alert rows, under a decision rule fixed before the run. With a person answering its questions, the agent raised a false alarm on \res{ResRulesOracleFARCollisionK}
batch-collision packs against \res{ResBaseOracleFARCollisionK} for the baseline, and its hit recall was
\res{ResRulesOracleHitRecall} against \res{ResBaseOracleHitRecall}. Without answers it abstained on
\res{ResRulesSkipAbstainK} packs. Neither language-model planner changed a verdict; the tool-calling planner raised the
median time per pack from \res{ResRulesOracleLatMedian}\,s to \res{ResLLMOracleLatMedian}\,s. The main limitation is the test
material: every pack is a rendered image, the vision fallback was tested live on one pack, and the run follows three fixes
made after a first run on the same packs, so results are optimistic.
